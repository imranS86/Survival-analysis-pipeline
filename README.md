# Survival Gene Discovery Pipeline
This repository presents a survival analysis pipeline applied to RNA-seq data from TCGA Pancreatic Adenocarcinoma (PAAD). The goal is to identify prognostic genes, construct a prognostic risk stratification model, and evaluate its predictive performance using survival analysis statistics and ROC curves. The pipeline is implemented in R using R Markdown, integrating statistical modeling, visualization, and reproducible research practices into a single workflow compiled in an interactive report below.

## 🔗 Interactive Report

👉 [View the full interactive HTML report](https://imrans86.github.io/surv/)

## The report includes:

- Data acquisition from TCGA, preprocessing and normalization  
- Survival modeling (univariate + multivariate Cox regression)  
- Feature selection using Lasso regression  
- Risk score model construction  
- Model evaluation plots (Kaplan–Meier and ROC curves)  
- Fully reproducible analytical workflow
